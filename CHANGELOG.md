# Changelog

## Unreleased

Initial analyser foundation, rule catalogue, reporting contracts, and local quality gates.

- **Package scaffold and verification gates** - Bootstrapped `gruff-php` as a Composer CLI package with the `bin/gruff` entry point, Symfony Console wiring, PHPUnit coverage, PHPStan level 10, and a readable preflight runner for static analysis plus tests. (`composer.json`, `composer.lock`, `bin/gruff`, `src/Console/Application.php`, `phpunit.xml.dist`, `phpstan.neon.dist`, `scripts/preflight-checks.sh`)
- **Source discovery and parser pipeline** - Added deterministic PHP file discovery with default ignored directories, missing/ignored path reporting, per-file parser diagnostics, token and AST capture, and parent-node attributes for rules that need enclosing class context. Parse errors are reported without aborting the whole run. (`src/Source/`, `src/Parser/`, `tests/Source/SourceDiscoveryTest.php`, `tests/Parser/PhpFileParserTest.php`, `tests/Fixtures/M02/`)
- **Rule engine, finding schema, and config** - Rules now share a `RuleInterface`, stable `RuleDefinition` metadata, default thresholds, enable/disable support, and deterministic registry execution. Findings carry rule ID, message, file, location, severity, pillar, tier, confidence, remediation, fingerprint, and metadata. JSON config supports per-rule threshold overrides and strict unknown-key validation. (`src/Rule/`, `src/Finding/`, `src/Config/`, `tests/Rule/RuleRegistryTest.php`, `tests/Finding/FindingTest.php`, `tests/Config/ConfigLoaderTest.php`)
- **CLI reporting and exit codes** - `analyse` now emits grouped text reports or schema-versioned JSON (`gruff.analysis.v1`) with tool metadata, run config, summary counts, diagnostics, ignored/missing paths, and findings. Exit codes are `0` for clean or below-threshold runs, `1` for findings meeting `--fail-on`, and `2` for expected config, parse, or input errors. (`src/Command/AnalyseCommand.php`, `src/Analysis/`, `src/Reporting/`, `tests/Console/GruffCliTest.php`, `tests/Fixtures/M04/`)
- **Size metrics** - Added seven threshold-backed size checks for file length, class/trait/enum length, method/function/closure length, parameter count, public method count, property count, and average method length per class. Counts use PhpParser source spans and dual warn/error thresholds. (`src/Rule/Size/`, `tests/Fixtures/M05/`)
- **Complexity metrics** - Added six structural complexity checks: cyclomatic complexity, cognitive complexity, maximum nesting depth, NPath complexity, Halstead volume, and maintainability index. Algorithms cover boolean operators, ternaries, nesting penalties, path multiplication, and inverse thresholds where lower scores are worse. (`src/Rule/Complexity/`, `tests/Fixtures/M06/`)
- **Dead code and waste rules** - Added class-local unused private method/property detection plus waste checks for unreachable statements, empty methods/classes, unused imports, unused parameters, and commented-out code. The scope stays conservative to avoid framework and inheritance false positives. (`src/Rule/DeadCode/`, `src/Rule/Waste/`, `tests/Fixtures/M07/`)
- **Naming rules** - Added naming checks for generic method names, single-character variables, boolean prefix conventions, Hungarian notation, vague standalone class names, mixed test naming conventions, and class/file mismatches. (`src/Rule/Naming/`, `tests/Fixtures/M08/`)
- **Documentation rules** - Added documentation quality checks for missing public PHPDoc, missing `@param` / `@return` / `@throws` tags, stale `@param` tags, useless docblocks, TODO/FIXME density, and missing project README files. (`src/Rule/Docs/`, `tests/Rule/Docs/DocsRulesTest.php`, `tests/Fixtures/M09/Docs/`)
- **Security dangerous-pattern rules** - Added heuristic AST rules for dangerous execution calls, unsafe `unserialize()`, weak crypto, variable include/require paths, SQL string concatenation, request-controlled `header()` calls, error suppression, silent catches, `extract()`/`compact()` on request data, insecure random sources, and disabled cURL SSL verification. Findings are labelled as pattern or heuristic checks and covered by safe-wrapper, config-disable, cumulative, and CLI fixtures. (`src/Rule/Security/`, `tests/Rule/Security/SecurityRulesTest.php`, `tests/Fixtures/M10/Security/`)
- **Secrets and sensitive-data rules** - Added source-tree text scanning for PHP and config-like files, with redacted findings for AWS keys, private key headers, common API keys, JWTs, database URLs with inline passwords, env-style secret values, high-entropy strings, PHI identifiers, and realistic PII in test fixtures. Non-PHP text files now bypass PHP parsing and only run text-safe rules; redaction tests assert full synthetic secrets stay out of text and JSON reports. (`src/Rule/Secrets/`, `src/Rule/SourceTextRuleInterface.php`, `src/Source/`, `tests/Rule/Secrets/SecretsRulesTest.php`, `tests/Fixtures/M11/Secrets/`)
- **PHP modernisation rules** - Added version-gated opportunity checks for constructor property promotion, readonly properties, public mutable properties, enum candidates, match-expression candidates, first-class callable arrays, named-argument opportunities, mixed-type overuse, and direct superglobal access. `minimumPhpVersion` config gates PHP 8.0/8.1 suggestions, and `@` suppression now reports once as a security finding with Modernisation as a secondary pillar. (`src/Rule/Modernisation/`, `src/Config/`, `src/Rule/Security/ErrorSuppressionRule.php`, `tests/Rule/Modernisation/ModernisationRulesTest.php`, `tests/Fixtures/M12/`)
- **Static test-quality rules** - Added PHPUnit/Pest scoped test-smell checks for no assertions, trivial assertions, conditional and looped tests, long tests with a single apparent SUT call, eager tests, mystery guests, excessive mocking, mock-only tests, sleeps, naming inconsistency, magic-number assertions, private reflection, `@dataProvider` annotations, trivial snapshots, missing SUT calls, setup bloat, and skipped tests without reasons. (`src/Rule/TestQuality/`, `tests/Rule/TestQuality/TestQualityRulesTest.php`, `tests/Fixtures/M13/`)
- **Infection mutation ingestion** - Added optional Infection JSON report ingestion via `--infection-report`, explicit opt-in execution via `--infection-run`, per-file MSI / covered MSI summaries, escaped and timed-out mutant findings, mutation budget checks, and baseline MSI regression checks. Missing Infection binaries and malformed reports become clear run diagnostics without making Infection a mandatory dependency. (`src/Mutation/`, `src/Command/AnalyseCommand.php`, `src/Reporting/TextReporter.php`, `tests/Mutation/InfectionReportParserTest.php`, `tests/Fixtures/M14/`)
- **Scoring, dashboard, and diff outputs** - Added A-F composite and per-pillar scoring, design composite findings for oversized complex methods, Git diff-mode filtering for changed lines/files, self-contained HTML dashboard output, Markdown PR-comment output, GitHub Actions annotations, hotspot-map JSON, and optional trend-history recording via `--history-file`. (`src/Scoring/`, `src/Diff/`, `src/Trend/`, `src/Reporting/`, `tests/Scoring/ScoreCalculatorTest.php`, `tests/Diff/GitDiffProviderTest.php`, `tests/Reporting/HtmlReporterTest.php`)
- **Config selection and auditable baselines** - Extended `.gruff.json` with project-relative path ignores, accepted abbreviation and secret-preview allowlists, and explicit rule selection by tier, pillar, and rule id. Added `--baseline` and `--generate-baseline` for fingerprint-backed suppression with stale-entry reporting, leaving inline suppression comments out of v0.1. (`src/Config/`, `src/Baseline/`, `src/Source/SourceDiscovery.php`, `src/Command/AnalyseCommand.php`, `tests/Config/ConfigLoaderTest.php`, `tests/Console/GruffCliTest.php`, `tests/Fixtures/M16/`)
- **Dogfood threshold calibration** - Workspace dogfood runs now have recorded performance and finding calibration evidence. Noisy defaults were tightened without dropping v0.1 coverage: identical project-level findings are de-duplicated, maintainability-index defaults moved to `55/35`, named-argument opportunities require 5 positional args unless a positional boolean is present, PHPDoc checks avoid marker-only and trivial-method busywork, useless-PHPDoc detection keeps generic types and tag descriptions, promoted constructors and empty exception markers are exempt from dead-code findings, fixture PII skips author/copyright emails, high-entropy scanning skips path literals, and no-assertion tests recognize legacy exception annotations plus mock expectations. (`src/Rule/`, `tests/Rule/`, `tests/Fixtures/`)
