# Glossary - gruff-php

## gruff-php

The current repository name and README title. At setup time this is a scaffold, not an implemented PHP package or application.

## Project-owned app surface

Files that define the actual future PHP project. At setup time this is only `README.md`; no PHP source, Composer metadata, or tests exist.

## goat-flow harness

The installed AI-agent workflow layer under `.goat-flow/`, `.claude/`, `.codex/`, and `.agents/skills/`. It is project infrastructure, not the PHP app itself.

## Agent-owned surface

Files owned by one AI coding agent runtime: Claude uses `CLAUDE.md` and `.claude/**`; Codex uses `AGENTS.md`, `.codex/**`, and `.agents/skills/**`.
